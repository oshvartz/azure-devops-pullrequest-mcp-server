# Project Brief: Azure DevOps PR API Tester

## Overview
A .NET application designed to interact with Azure DevOps Pull Requests through its API. The project aims to provide a tool for automated testing and management of pull requests.

## Core Requirements
1. Interface with Azure DevOps API
2. Retrieve and process pull request details
3. Parse Azure DevOps URLs effectively
4. Handle authentication and API communication securely

## Goals
- Streamline pull request management through automation
- Provide reliable API interaction with Azure DevOps
- Enable efficient testing and validation of pull requests
- Maintain clean code architecture and separation of concerns

## Scope
- Pull request data retrieval and processing
- URL parsing for Azure DevOps repositories
- API client implementation for Azure DevOps
- Models for representing pull request data
